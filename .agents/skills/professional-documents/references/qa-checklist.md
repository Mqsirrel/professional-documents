# Visual QA Checklist

Run after rendering the document.

## Content
- [ ] All requested sections exist.
- [ ] No accidental omissions or duplicated sections.
- [ ] Headings match the intended hierarchy.

## Layout
- [ ] No clipped or overflowing content.
- [ ] No orphan headings.
- [ ] No accidental nearly-empty pages.
- [ ] Margins are consistent.
- [ ] Page breaks occur at sensible boundaries.
- [ ] Tables remain within page boundaries.
- [ ] Captions remain associated with figures/tables.

## Typography
- [ ] Body text is comfortably readable.
- [ ] Heading levels are visually consistent.
- [ ] Font changes have a reason.
- [ ] Line spacing and paragraph spacing are consistent.

## Components
- [ ] Headers and footers are aligned.
- [ ] Page numbers are correct.
- [ ] Lists and numbering are consistent.
- [ ] Tables are scannable.
- [ ] Callouts are visually subordinate to the main hierarchy.

## RTL / mixed language
- [ ] Arabic paragraphs are correctly RTL.
- [ ] English identifiers, URLs, code, and numbers retain appropriate LTR behavior.
- [ ] Mixed-script tables render correctly.

## Final judgment
Rate each from 1–5:
- Hierarchy
- Readability
- Consistency
- Page composition
- Professional credibility

If any category is below 4, revise and render again.
